# Inertia page structure

- `Home/` — public homepage and public-facing pages.
- `Home/Academic/` — public academic information pages.
- `Admin/` — administrator pages.
- `Student/` — student portal pages.
- `Lecturer/` — lecturer portal pages.
- `Shared/` — authenticated pages shared across roles.

The folder name must match the first segment of the Inertia component name returned by the backend.
